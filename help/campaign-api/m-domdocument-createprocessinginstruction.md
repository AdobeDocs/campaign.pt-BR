# createProcessingInstruction

Cria uma nova instrução de processamento.

```text
createProcessingInstruction (target, data)
```

## Parâmetros

**target** Destino da instrução de processamento, por exemplo &lt;?php ... ?>.

**dados** Cadeia de caracteres para inserir na instrução.

## Valor de retorno

[processinginstruction](c-domnode.md) criada.
