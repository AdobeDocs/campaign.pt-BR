# GenerateLinkDimension

Gera uma dimensão com base em um link.

```text
XML result = GenerateLinkDimension ( XML dimension, XML linklevels )
```

## Parâmetros

Dimension de **dimensão** para inserir

**linklevels** níveis disponíveis

## Retornar valor(es)

**resultado** Dimensão inserida
