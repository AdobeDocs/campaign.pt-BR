# GenerateAnalysisWidget

Gera o widget para exibição.

```text
XML javascript = GenerateAnalysisWidget ( XML entity, String javascriptId, XML queryResult )
```

## Parâmetros

Documento XML **entidade** descrevendo o widget

**javascriptId** ID exclusiva do widget

Documento XML **queryResult** contendo os dados

## Retornar valor(es)

JavaScript de criação do widget **javascript**
