# Implantar

Implanta espaços em um ambiente.

```text
Deploy ( XML offerSpaceFilter, Number offerEnv )
```

## Parâmetros

**offerSpaceFilter** Condição de filtragem que define os espaços a serem copiados

**offerEnv** Identificador do ambiente de destino

## Retornar valor(es)

Nenhum.

## Recursos

**Esquema:** [nms:offerSpace](s-nms-offerspace.md)

**Estático:**

Sim
