# substringData

Extrair uma parte do texto.

```text
substringData (offset, count)
```

## Parâmetros

**deslocamento** Posição do primeiro caractere (0 para o primeiro caractere).

**count** Número de caracteres a serem extraídos.

## Valor de retorno

Sequência de caracteres extraída.
