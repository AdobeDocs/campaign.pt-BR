# DOMElement (Classe)

Um nó do tipo elemento.

## Métodos

| Método | Descrição |
| --- | --- |
| [toXMLString](m-domelement-toxmlstring.md) | Converte o elemento em uma cadeia de caracteres. |
| [getFirstElement](m-domelement-getfirstelement.md) | Retorna o primeiro elemento filho verificando os critérios fornecidos. |
| [hasElement](m-domelement-haselement.md) | Testa se o elemento tem um elemento filho verificando os critérios fornecidos. |
| [getValue](m-domelement-getvalue.md) | Retorna o valor do nó referenciado pelo XPath fornecido. |
| [getBooleanValue](m-domelement-getbooleanvalue.md) | Retorna o valor do nó booleano referenciado pelo XPath fornecido. |
| [getDateValue](m-domelement-getdatevalue.md) | Retorna o valor do tipo date+hour da referência do nó pelo XPath fornecido. |
| [getNumberValue](m-domelement-getnumbervalue.md) | Retorna o valor do nó digital referenciado pelo XPath fornecido. |
| [getElements](m-domelement-getelements.md) | Retorna a lista de elementos filho com o nome especificado, pertencente a este elemento. |
| [getAttribute](m-domelement-getattribute.md) | Retorna o valor do atributo. |
| [setAttribute](m-domelement-setattribute.md) | Altere o valor de um atributo ou crie um novo atributo. |
| [removerAtributo](m-domelement-removeattribute.md) | Excluir um atributo. |
| [getElementsByTagName](m-domelement-getelementsbytagname.md) | Retorna a lista de todos os elementos secundários com o nome especificado. |
| [getAttributeNS](m-domelement-getattributens.md) | Retorna o valor do atributo. |
| [setAttributeNS](m-domelement-setattributens.md) | Altere o valor de um atributo ou crie um novo atributo. |
| [removeAttributeNS](m-domelement-removeattributens.md) | Excluir um atributo. |
| [getElementsByTagNameNS](m-domelement-getelementsbytagnamens.md) | Retorna a lista de todos os elementos secundários com o nome especificado. |
| [hasAttribute](m-domelement-hasattribute.md) | Testar a existência de um atributo. |
| [hasAttributeNS](m-domelement-hasattributens.md) | Testar a existência de um atributo. |
| [setIdAttribute](m-domelement-setidattribute.md) | Declara o atributo especificado como um atributo do tipo ID. |
| [setIdAttributeNS](m-domelement-setidattributens.md) | Declara o atributo especificado como um atributo do tipo ID. |
