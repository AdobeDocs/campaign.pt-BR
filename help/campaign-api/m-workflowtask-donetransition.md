# doneTransition

Retorna a transição &quot;concluído&quot; da atividade.

```text
doneTransition ()
```

## Parâmetros

Nenhum.

## Valor de retorno

A primeira atividade &quot;done&quot; é encontrada; caso contrário, é nula.
