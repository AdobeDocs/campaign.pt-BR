# EvaluateJavaScriptTemplate

Avaliação do modelo JavaScript (JST).

```text
[ XML context, String result ] = EvaluateJavaScriptTemplate ( String name, String template, XML context )
```

## Parâmetros

**nome** Nome do script.

Documento **modelo** a ser avaliado.

Contexto **context** ao avaliar o documento.

## Retornar valor(es)

Contexto **context** ao avaliar o documento.

**resultado** Documento resultante da avaliação.
