# Transformar

Publicar a transformação de um conteúdo

```text
[ String format, String result ] = Transform ( String publishingId, String modelName, XML content )
```

## Parâmetros

**publishingId** Identificador do modelo de publicação

**modelName** Nome do modelo de transformação

**conteúdo** Dados de conteúdo a serem transformados

## Retornar valor(es)

**formato** Formato de saída

**resultado** Resultado da transformação
