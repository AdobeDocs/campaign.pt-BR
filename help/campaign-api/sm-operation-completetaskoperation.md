# ConcluirOperaçãoDeTarefa

Conclui uma tarefa criada no contexto de uma campanha.

```text
XML taskOut = CompleteTaskOperation ( XML taskIn, XML parameter )
```

## Parâmetros

**taskIn** Tarefa de entrada

**parâmetro** Configuração do contexto da campanha

## Retornar valor(es)

**taskOut** Atualizar tarefa

## Recursos

**Esquema:** [nms:operation](s-nms-operation.md)

**Estático:**

Sim
