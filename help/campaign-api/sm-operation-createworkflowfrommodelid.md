# CreateWorkflowFromModelId

Crie um fluxo de trabalho em uma campanha baseada em um modelo de fluxo de trabalho.

```text
Number workflowId = CreateWorkflowFromModelId ( Number modelId, XML operationPlanning )
```

## Parâmetros

**modelId** Identificador do modelo de fluxo de trabalho

**operationPlanning** Programação de campanha

## Retornar valor(es)

**workflowId** Identificador da instância criada

**Esquema:** [nms:operation](s-nms-operation.md)

Sim
