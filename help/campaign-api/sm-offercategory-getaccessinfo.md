# GetAccessInfo

Retorna as propriedades herdadas do modo anônimo.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## Parâmetros

**categoryId** ID de Categoria

## Retornar valor(es)

**anonymous** Especifica se as ofertas de categoria são ou não anônimas

**parentAnonymous** especifica se as ofertas de categoria pai são ou não anônimas

**Esquema:** [nms:offerCategory](s-nms-offercategory.md)

Sim
