# Proteção de dados: funções de escape

O Adobe Campaign fornece um conjunto de funções que fornecem proteção contra os ataques mais frequentes: injeções de SQL, ataques de XSS etc.

As funções de escape devem ser utilizadas sob a supervisão dos operadores e a Adobe não pode ser responsabilizada pela má utilização ou ausência de utilização dessas funções durante os desenvolvimentos.

A regra geral é a seguinte:

**Todos os parâmetros devem ter escape. A função usada para o escape depende do formato de destino dos dados.**

## Escape simplificado

Nos JSSPs, o Adobe Campaign fornece a tag &#39;&lt;%=&#39;, que permite o escape de uma variável usada em um XML gerado ou em uma entidade HTML. Este método é mais conveniente e é equivalente a NL.XML.escape(). O exemplo a seguir ilustra o uso da tag para escapar um parâmetro:

```xml
<li>
<%= strRecipientList %>
</li>
```

## Escape avançado:

O Adobe Campaign fornece quatro funções que permitem escapar um parâmetro, dependendo do formato de destino. Para acessar essas funções de escape, nomeie os seguintes arquivos, respectivamente:

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data) para usar o escape em uma variável usada em um XML gerado ou em uma entidade HTML. Esta função é equivalente à sintaxe &#39;&lt;%=&#39;. Essa função é definida no pacote NL.XML.

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data) para escapar um parâmetro que pode ser usado em uma consulta SQL. Esta função coloca automaticamente a expressão entre aspas simples. Essa função é definida no pacote NL.SQL.

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data) para escapar um parâmetro destinado a ser usado em uma expressão XTK. Essa função é definida no pacote NL.XTK.

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data) para escapar uma variável usada no javascript executado no lado do cliente. Essa função é definida no pacote NL.JS.

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

Aviso: o Adobe Campaign não garante a durabilidade dessas funções para versões posteriores.
