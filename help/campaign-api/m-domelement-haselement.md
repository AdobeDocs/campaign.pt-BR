# hasElement

Testa se o elemento tem um elemento filho verificando os critérios fornecidos.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## Parâmetros

**tagName** Nome do elemento pesquisado.

**attrName** Nome de um atributo que precisa verificar um determinado valor.

**attrValue** Valor de atributo.

## Valor de retorno

true se o elemento tiver um filho verificando os dados fornecidos; caso contrário, false.
