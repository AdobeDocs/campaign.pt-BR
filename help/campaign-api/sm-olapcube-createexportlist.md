# CriarListaDeExportações

Cria a lista para a qual as entidades do carrinho serão exportadas.

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## Parâmetros

**rótulo** Rótulo da lista

**folderId** ID da pasta na qual a lista será criada (0 para usar a pasta padrão).

## Retornar valor(es)

ID de **listId** da lista recém-criada
