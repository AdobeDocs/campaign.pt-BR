# DeployTriggerMessages

Publicar as mensagens transacionais selecionadas nas instâncias de execução

```text
DeployTriggerMessages ( XML deliveries, Boolean localPublish )
```

## Parâmetros

**entregas** Condições de filtro para definir as mensagens transacionais a serem implantadas

**localPublish** Publicar somente na instância de controle?

## Retornar valor(es)

Nenhum.
