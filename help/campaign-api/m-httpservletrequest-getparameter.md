# getParameter

Retorna o valor de um parâmetro de consulta.

```text
getParameter (name)
```

## Parâmetros

**nome** Nome do parâmetro.

## Valor de retorno

O valor do parâmetro solicitado.

## Recursos

**Método de classe:** [HttpServletRequest](c-httpservletrequest.md)

**Disponível em:**

* JSSP
* WebApp
