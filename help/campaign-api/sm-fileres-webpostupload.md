# WebPostUpload

Finalize o armazenamento do recurso após o upload (de uma página da Web) no servidor, dependendo do tipo de armazenamento usado. Recupera a página de código e o tipo de conteúdo.

```text
fileRes.WebPostUpload ( XML params )
```

## Parâmetros

**params** Para armazenamento do tipo &#39;espaço de trabalho&#39;: @formerFileName contém o nome anterior no espaço de trabalho. Se você quiser salvar a entidade imediatamente: @immediateSave deve ser definido como &#39;true&#39;

## Retornar valor(es)

Nenhum.
