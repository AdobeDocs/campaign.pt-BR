# GetCompatibleOfferViews

Retorna a lista de representações compatíveis com esta oferta.

```text
XML offerViews = GetCompatibleOfferViews ( Number offerId )
```

## Parâmetros

**offerId** ID da oferta

## Retornar valor(es)

**offerViews** Representações compatíveis
