# toString

Retorna o conteúdo de [MemoryBuffer](c-memorybuffer.md) na forma de uma cadeia de caracteres.

```text
toString ( [codePage ])
```

## Parâmetros

**codePage** Um número inteiro que codifica a página de caracteres usados. Por padrão, MemoryBuffer.CODEPAGE\_UTF8.

## Valor de retorno

O conteúdo de um carimbo na forma de uma cadeia de caracteres.
