# MoverNó

Mover pasta na árvore de navegação

```text
MoveNode ( String key, String parentKey, Number order, String fullName )
```

## Parâmetros

Chave do nó **key**

**parentKey** Chave pai

**order** Novo índice de nó

**fullName** Nome completo (não está vazio para alterar o pai na árvore)

## Retornar valor(es)

Nenhum.
