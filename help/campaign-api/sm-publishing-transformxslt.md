# TransformarXSLT

Transformação de publicação baseada em XSLT

```text
String result = TransformXSLT ( String source, String namespace, String format, String contentId )
```

## Parâmetros

Conteúdo da folha de estilos XSLT de **origem**

**namespace** Namespace usado para diretivas xsl:import relativas

**formato** Formato de saída

**contentId** Identificador de conteúdo

## Retornar valor(es)

**resultado** Resultado da transformação
