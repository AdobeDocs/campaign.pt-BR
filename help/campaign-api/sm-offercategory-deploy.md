# Implantar

Implantação de categorias em um ambiente.

```text
Deploy ( XML offerCategoryFilter, Number offerEnv )
```

## Parâmetros

**offerCategoryFilter** Condição de filtragem que define as categorias a serem copiadas

**offerEnv** Identificador do ambiente de destino

## Retornar valor(es)

Nenhum.
