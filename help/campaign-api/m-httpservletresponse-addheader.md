# addHeader

Adiciona um cabeçalho HTTP adicional à resposta.

```text
addHeader (nom, valeur)
```

## Parâmetros

**nom** Nome do cabeçalho a ser adicionado.

**valeur** Valor do cabeçalho adicionado.

## Valor de retorno

Nenhum.

## Recursos

**Método de classe:** [HttpServletResponse](c-httpservletresponse.md)

**Disponível em:**

* JSSP
* WebApp
