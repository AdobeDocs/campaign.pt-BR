# DeliveryValidation

Aprovação de uma entrega em uma campanha.

```text
DeliveryValidation ( Number deliveryId, Number type, Boolean refused, String comment )
```

## Parâmetros

**deliveryId** Identificador de entrega

**type** Tipo de aprovação (targeting=0, content=1, budget=2, extraction=3)

**recusou** Rejeitar

Comentário **comentário**

## Retornar valor(es)

Nenhum.
