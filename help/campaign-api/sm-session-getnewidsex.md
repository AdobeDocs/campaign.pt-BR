# GetNewIdsEx

Obtém uma lista dos identificadores exclusivos do banco de dados, com um nome de sequência.

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## Parâmetros

**count** Número de identificadores que este método deve retornar

**sequência** Nome da sequência a ser incrementada

## Retornar valor(es)

**idList** Lista de identificadores separados por vírgulas
