# mkdir

Cria um diretório com o caminho do objeto [File](c-file.md) atual.

```text
mkdir ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Nenhum.

## Observações

Também cria diretórios intermediários, se necessário. Uma exceção é gerada em caso de erro.
