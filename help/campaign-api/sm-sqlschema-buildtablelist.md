# BuildTableList

Obtém uma lista de nomes de tabela.

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## Parâmetros

**dataSource** ID da fonte de dados

**tablePattern** Máscara do nome da tabela

## Retornar valor(es)

**tableList** listas de tabelas existentes
