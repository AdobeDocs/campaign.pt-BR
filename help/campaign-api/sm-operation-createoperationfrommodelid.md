# CreateOperationFromModelId

Crie uma campanha com base em um modelo de campanha.

```text
Number operationId = CreateOperationFromModelId ( Number modelId, XML operationPlanning )
```

## Parâmetros

**modelId** Identificador do modelo de campanha

**operationPlanning** Programação de campanha

## Retornar valor(es)

**operationId** Identificador da instância criada
