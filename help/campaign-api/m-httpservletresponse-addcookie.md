# addCookie

Adiciona um cookie à resposta.

```text
addCookie (cookie)
```

## Parâmetros

Cookie **cookie** para adicionar.

## Valor de retorno

Nenhum.

## Recursos

**Método de classe:** [HttpServletResponse](c-httpservletresponse.md)

**Disponível em:**

* JSSP
