# DOMAttr (Classe)

Um nó de tipo de atributo.

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [isId](p-domattr-isid.md) | true se o atributo for um tipo de ID. |
| [nome](p-domattr-name.md) | Nome do atributo. |
| [ownerElement](p-domattr-ownerelement.md) | O elemento com este atributo ou nulo. |
| [especificado](p-domattr-specified.md) | true se o valor for especificado explicitamente (esse não é um valor implícito por padrão). |
| [valor](p-domattr-value.md) | Valor de texto do atributo. |
