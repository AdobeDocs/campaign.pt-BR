# CompleteURLParams

Preencha o URL de sucesso

```text
String result = CompleteURLParams ( String formName, String xpathParams, XML recipient )
```

## Parâmetros

Nome do formulário **formName**

**xpathParams** Lista de XPaths separados por vírgulas para retornar

**recipient** Dados do destinatário

## Retornar valor(es)

**resultado** Retorna parâmetros para a URL

**Esquema:** [nms:webForm](s-nms-webform.md)
