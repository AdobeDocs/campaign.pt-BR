# digestStrSha224

Calcula o hash SHA-224 de uma cadeia de caracteres. A cadeia de caracteres é codificada automaticamente em UTF-8 antes do cálculo.

```text
digestStrSha224 (string)
```

## Parâmetros

**cadeia** A cadeia de caracteres na qual o hash deve ser calculado.

## Valor de retorno

O hash SHA-224 da cadeia de caracteres transmitida como um parâmetro.
