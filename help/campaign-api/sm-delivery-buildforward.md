# BuildForward

Cria a página HTML.

```text
[ String content, Number responseCode ] = BuildForward ( String crypted, XML parameters )
```

## Parâmetros

**criptografado** Criptografia reversível para identificadores de partes de mensagens e entregas

**parâmetros** parâmetros de URL

## Retornar valor(es)

**conteúdo** Conteúdo da página

Resposta HTTP **responseCode** em caso de erro
