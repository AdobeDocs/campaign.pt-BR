# Exceções do JavaScript

Por padrão, quando ocorre um erro, o script que está sendo executado é interrompido. A versão 4.05 em diante, no entanto, permite capturar erros e manipulá-los para continuar o processamento do script.

As exceções geradas pelo Adobe Campaign são códigos de erro (tipo `Number`).

## Exemplo

Este exemplo tenta recuperar uma página da Web de um endereço inválido e gera uma exceção da função [getUrl()](f-geturl.md).

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
