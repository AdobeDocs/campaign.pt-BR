# localOrder

Pedidos de campanha locais em um pacote para marketing distribuído

## Métodos

| Método | Descrição |
| --- | --- |
| [Cancelar](sm-localorder-cancel.md) | Cancelar o pedido. |
| [CriarDoCatálogo](sm-localorder-createfromcatalog.md) | Criar um pedido a partir de um pacote. |
| [AvaliarConteúdo](sm-localorder-evaluatecontent.md) | Avalia o conteúdo de uma entrega vinculada a uma ordem. Essa avaliação será realizada ao fazer pedidos usando direitos de operador e antes da criação da campanha local. |
| [EvaluateContentFromId](sm-localorder-evaluatecontentfromid.md) | Avalia o conteúdo de uma entrega vinculada a uma ordem. Essa avaliação será realizada ao fazer pedidos usando direitos de operador e antes da criação da campanha local. |
| [EvaluateDeliveryBudget](sm-localorder-evaluatedeliverybudget.md) | Avaliar orçamento de entrega. |
| [AvaliarDestino](sm-localorder-evaluatetarget.md) | Avalia o direcionamento de campanha para cada entrega de campanha vinculada a um pedido. Essa avaliação será realizada ao fazer pedidos usando direitos de operador e antes da criação da campanha local. |
| [EvaluateTargetFromId](sm-localorder-evaluatetargetfromid.md) | Avalia o direcionamento de campanha para cada entrega de campanha vinculada a um pedido. Essa avaliação será realizada ao fazer pedidos usando direitos de operador e antes da criação da campanha local. |
| [ExecuteTarget](sm-localorder-executetarget.md) | Executa o direcionamento de campanha vinculado ao pedido. |
| [Reservar](sm-localorder-reserve.md) | Pedido. |
| [Validação](sm-localorder-validation.md) | Aprovar o pedido. |
