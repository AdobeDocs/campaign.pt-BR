# getFirstElement

Retorna o primeiro elemento filho verificando os critérios fornecidos.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## Parâmetros

**tagName** Nome do elemento pesquisado.

**attrName** Nome de um atributo que precisa verificar um determinado valor.

**attrValue** Valor de atributo.

## Valor de retorno

Primeiro elemento que verifica os critérios fornecidos ou nulo.
