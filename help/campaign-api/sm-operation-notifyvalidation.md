# NotifyValidation

Notificação de aprovação em uma campanha.

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## Parâmetros

**deliveryId** Identificador de entrega

**target** Validação de direcionamento

**conteúdo** Aprovação de conteúdo

**Orçamento** Aprovação de orçamento

**extração** Aprovação do arquivo de extração

**FCP** Aprovação de prova

**sandbox** Aprovação de estimativa de público alvo

**edição** edição de conteúdo

**externo** Aprovação de conteúdo externo

## Retornar valor(es)

Nenhum.
