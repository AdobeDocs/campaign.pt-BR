# transitionByName

Retorna as transições correspondentes ao nome especificado.

```text
transitionByName (name)
```

## Parâmetros

**nome** Nome da transição.

## Valor de retorno

A transição com o nome passado como um parâmetro, senão nulo se a atividade não tiver uma transição com esse nome.
