# GerarDimensãoDeNívelÚnico

Gera uma dimensão de nível único com base em um campo.

```text
XML result = GenerateSingleLevelDimension ( XML dimension, XML field )
```

## Parâmetros

Dimension de **dimensão** para inserir

**campo** Campo ou expressão usada

## Retornar valor(es)

**resultado** Dimensão inserida
