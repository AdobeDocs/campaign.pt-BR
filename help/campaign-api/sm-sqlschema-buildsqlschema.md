# BuildSqlSchema

Gera o código de um esquema a partir da estrutura física da tabela fornecida nos parâmetros.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## Parâmetros

**dataSource** ID da fonte de dados

**tableName** Nome da tabela

## Retornar valor(es)

**esquema** Esquema gerado
