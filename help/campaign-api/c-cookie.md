# Cookie (Classe)

Representa um cookie trocado pelo servlet e pelo navegador da Web.

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [nome](p-cookie-name.md) | Nome do cookie. |
| [comentário](p-cookie-comment.md) | Comentário que descreve a função do cookie, nulo se indefinido. |
| [domínio](p-cookie-domain.md) | Nome de domínio do cookie. |
| [maxAge](p-cookie-maxage.md) | Duração do cookie em segundos. |
| [caminho](p-cookie-path.md) | Caminho com base no qual o navegador da Web encaminha o cookie. |
| [seguro](p-cookie-secure.md) | true se o cookie só puder ser encaminhado por meio de um protocolo seguro. |
| [valor](p-cookie-value.md) | Valor do cookie. |
| [versão](p-cookie-version.md) | Versão do protocolo com a qual o cookie é compatível. |

## Recursos

**Disponível em:**

* JSSP
* WebApp
