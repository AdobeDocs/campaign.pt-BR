# toXMLString

Converte o documento XML em uma cadeia de caracteres.

```text
toXMLString (format)
```

## Parâmetros

**format** Um booliano para formatar o documento XML.

## Valor de retorno

Nenhum.

## Observações

Esse método adiciona o prólogo, ao contrário do método com o mesmo nome sobre elementos.
