# insertData

Insere uma cadeia de caracteres no texto em uma posição específica.

```text
insertData (offset, arg)
```

## Parâmetros

**deslocamento** Posição de inserção (0 para o primeiro caractere).

**arg** Cadeia de caracteres a ser inserida.

## Valor de retorno

Nenhum.
