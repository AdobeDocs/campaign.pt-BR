# appendBase64

Acrescenta dados de uma cadeia de caracteres codificada na base 64 ao final do buffer.

```text
appendBase64 (string)
```

## Parâmetros

**cadeia** Uma cadeia de caracteres que representa os dados binários codificados na base 64 a serem adicionados ao buffer.

## Valor de retorno

Nenhum.
