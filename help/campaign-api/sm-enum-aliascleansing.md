# AliasCleansing

Atualizar banco de dados usando listas discriminadas limpas.

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## Parâmetros

**onde** Filtro de enumerações.

**fromDate** Data de início das respostas da pesquisa.

**refreshHit** atualização de ocorrências.

**resetHit** Atualize a ocorrência desde o início.

## Retornar valor(es)

Nenhum.
