# desofuscar

Não ofusca o inteiro ofuscado anteriormente graças a [ofuscar](f-obfuscate.md).

```text
unobfuscate (value [, version ])
```

## Parâmetros

**value** O inteiro a ser ofuscado.

**versão** a versão de liberação de ofuscação a ser aplicada. 0 por padrão.

## Valor de retorno

O inteiro ofuscado anteriormente por [obfuscate](f-obfuscate.md).

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia
* Importação
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
