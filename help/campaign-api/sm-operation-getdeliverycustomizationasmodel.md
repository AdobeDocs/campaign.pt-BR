# GetDeliveryCustomizationAsModel

Copie os modelos de campo de personalização selecionados.

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## Parâmetros

**selection** Elemento que contém os identificadores de modelo selecionados

Elemento **parentIn** que contém as personalizações existentes

## Retornar valor(es)

**parentOut** retorna o elemento com os novos modelos adicionados
