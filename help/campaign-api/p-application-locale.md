# localidade

Retorna uma cadeia de caracteres que corresponde à instância Local.

```text
locale
```

## Observações

O Local é um código que define configurações regionais. Ele é composto de um código de idioma seguido por um código de país, separado por &quot;-&quot;. Exemplos de valores:

* en-US - Inglês, Estados Unidos
* en-GB - Inglês, Grã-Bretanha
* fr-FR - Francês, França
* de-DE - Alemão, Alemanha
* es-ES - Espanhol, Espanha
