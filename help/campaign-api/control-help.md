# Ajuda

Exibir um texto e uma imagem.

![Controle de ajuda](assets/help.67cf3e33.png)

## Propriedades

**img - cadeia de caracteres** Imagem associada.

**rótulo - cadeia de caracteres** Texto a ser exibido.

## Observações

Exemplo:

```xml
      <static type="help" label="Please enter your name here."/>

<static type="help">Please enter your name here.</static>
```
