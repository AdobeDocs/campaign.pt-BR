# fileCount

Retorna o número de arquivos no arquivo morto.

```text
fileCount
```

## Observações

O arquivo morto deve ter sido aberto com o método ⌐[open()](m-zipfile-open.md) antes que você possa usar esse método. Caso contrário, uma exceção será gerada.
