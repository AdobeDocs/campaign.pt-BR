# postEvent

Ativa uma transição.

```text
postEvent (transition)
```

## Parâmetros

**transição** A transição a ser ativada.

## Valor de retorno

Nenhum.

## Observações

A atividade alvo da transição é ativada e recebe as variáveis da tarefa.
