# replaceData

Substituir uma parte do texto.

```text
replaceData (offset, count, arg)
```

## Parâmetros

**deslocamento** Posição do primeiro caractere a ser excluído (0 para o primeiro caractere).

**count** Número de caracteres a serem excluídos.

**arg** Cadeia de caracteres a ser inserida.

## Valor de retorno

Nenhum.
