# getUUID

Geração de um identificador exclusivo (ID exclusiva universal).

```text
getUUID ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Uma string de caracteres que contém um identificador exclusivo do tipo &quot;550E8400-E29B-41D4-A716-446655440000&quot;.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
