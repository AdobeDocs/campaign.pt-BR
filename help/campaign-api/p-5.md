# Uso de datas

Este capítulo detalha as funções a serem usadas para manipular datas nos programas do JavaScript executados no servidor (workflow, JSSP etc.).

## Datas e fusos horários

No JavaScript, as datas são armazenadas em UTC. Isso significa que você só precisa se preocupar com fusos horários para construção de datas ou conversão em cadeias de texto para exibição interna ou armazenamento. Para conversão de datas, há duas categorias de função:

* as funções da biblioteca do JavaScript (date.toString(), date.toLocaleString(), date.getHours(), ...),
* as funções da plataforma Adobe Campaign ( [formatDate(date, format)](f-formatdate.md) ).

Por convenção, as primeiras usam o fuso horário da máquina, enquanto as últimas usam um fuso horário dependendo do contexto: geralmente o do operador atual, mas esse comportamento pode ser modificado para exportações ou workflows, por exemplo.

## Obter a data atual

Há duas maneiras de obter a data atual no JavaScript:

* new Date() cria um novo objeto Date inicializado com a data atual. A data coincide com a hora da máquina em que o script é executado.
* [getCurrentDate()](f-getcurrentdate.md) retorna a data atual com base na hora do servidor de banco de dados.

A função [getCurrentDate()](f-getcurrentdate.md) é preferível à primeira solução, especialmente quando a data deve ser comparada a outras datas do banco de dados ou ser gravada no banco de dados. Esse método reduz o risco de discrepâncias (até vários minutos) vinculadas às diferenças de tempo entre o servidor de aplicativos e o servidor de banco de dados

## Exibição de data

A conversão de uma data em uma cadeia de caracteres para fins de exibição usa a função [formatDate](f-formatdate.md).

## Conversão de uma data de um documento XML

As datas armazenadas em um documento XML proveniente do banco de dados do Adobe Campaign estão no formato de texto: elas podem ser convertidas usando a função [parseTimeStamp](f-parsetimestamp.md). Normalmente, isso afeta documentos XML retornados pelo método [ExecuteQuery](sm-querydef-executequery.md). Exemplo:

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## Inserir uma data em um documento XML

Se você deseja gravar uma data em um atributo XML, salvar um documento (método [Write](sm-session-write.md)) ou inserir uma data literal na expressão de uma consulta, a data terá que ser convertida no formato ISO8601. Há um método na biblioteca de funções xtk:shared/nl.js para converter uma data neste formato: o método NL.XTK.formatDateTime(date). A biblioteca pode ser carregada usando a função loadLibrary:

```javascript
loadLibrary("xtk:shared/nl.js")
```

ou usando a diretiva de página no caso de uma página dinâmica do JavaScript (JSSP):

```xml
<%@ page import="xtk:shared/nl.js" %>
```

Aviso: não é possível usar loadLibrary para todos os scripts. Por exemplo, você não pode alterar uma biblioteca de funções do JavaScript em um script de personalização de email. Exemplo : este exemplo mostra a construção de uma consulta usando uma data literal.

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
