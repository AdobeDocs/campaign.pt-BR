# HtmlToText

Converte conteúdo HTML em texto sem formatação

```text
String textContent = HtmlToText ( String htmlContent )
```

## Parâmetros

**htmlContent** conteúdo HTML para converter

## Retornar valor(es)

**textContent** Retorna o texto convertido
