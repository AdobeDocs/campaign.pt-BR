# pasta

Pastas na hierarquia de navegação

## Métodos

| Método | Descrição |
| --- | --- |
| [CheckEntityWriteRight](sm-folder-checkentitywriteright.md) | Retorna “TRUE” se o operador atual tiver acesso de gravação em uma determinada entidade |
| [DropSelection](sm-folder-dropselection.md) | Mover seleção para uma pasta da árvore de navegação |
| [FindFirstAuthorized](sm-folder-findfirstauthorized.md) | Localiza a primeira pasta qualificada para o usuário atual, cumprindo a condição folderFilter. |
| [HasFolderWriteRight](sm-folder-hasfolderwriteright.md) | Retorna “TRUE” se houver acesso de gravação a uma pasta |
| [InheritParentFolderRights](sm-folder-inheritparentfolderrights.md) | Atualizar a entidade da pasta com os direitos da pasta pai |
| [LoadChildren](sm-folder-loadchildren.md) | Carregar a lista de filhos de um determinado nó |
| [LoadChildrenWithPath](sm-folder-loadchildrenwithpath.md) | Carregar a lista de filhos de um determinado nó |
| [MoverNó](sm-folder-movenode.md) | Mover pasta na árvore de navegação |
| [MoverSeleção](sm-folder-moveselection.md) | Mover seleção para uma pasta da árvore de navegação |
| [NovaPasta](sm-folder-newfolder.md) | Criar uma pasta |
