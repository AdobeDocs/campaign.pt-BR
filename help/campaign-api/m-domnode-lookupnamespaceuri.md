# lookupNamespaceURI

Pesquisado o URI do namespace vinculado ao prefixo fornecido.

```text
lookupNamespaceURI (prefix)
```

## Parâmetros

Prefixo **prefix**.

## Valor de retorno

URI do namespace ou uma cadeia de caracteres vazia, se não encontrada.

## Recursos

**Método da classe:** [DOMNode](c-domnode.md)

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia
* Importação
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
