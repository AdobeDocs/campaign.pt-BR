# HttpClientRequest

Cria um novo objeto para executar uma consulta de cliente HTTP.

```text
HttpClientRequest ( [URL ])
```

## Parâmetros

URL **URL** do destinatário da consulta.

## Valor de retorno

Nenhum.

## Observações

Se o comando FTP falhar, uma exceção será gerada. Exemplo:

```javascript
var http = new HttpClientRequest("http://www.somewhere.com/login")

var buffer = new MemoryBuffer()
buffer.fromString("MyLogin" + ':' + "MyPassword", "iso-8859-1")

http.header["Authorization"] = "Basic " + buffer.toBase64()
http.header["Content-Type"] = "text/xml; charset=utf-8"

http.method = "SEARCH"
http.body = "<xml>any content</xml>"

http.execute()
       
```
