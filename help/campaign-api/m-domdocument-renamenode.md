# renameNode

Altera o nome de um elemento ou atributo.

```text
renameNode (node, namespaceURI, qualifiedName)
```

## Parâmetros

Nó **node** do tipo elemento/atributo.

**namespaceURI** Novo URI de namespace.

**qualifiedName** Novo nome qualificado.

## Valor de retorno

Nó renomeado. Pode ser o nó especificado ou um nó que substitui o antigo.

**Método de classe:** [DOMDocument](c-domdocument.md)

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
