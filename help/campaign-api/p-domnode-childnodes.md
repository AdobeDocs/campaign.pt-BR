# childNodes

Retorna a lista de nós filhos na forma de uma tabela.

```text
childNodes
```

## Observações

Essa propriedade cria uma nova tabela para cada acesso. Portanto, é melhor manter a tabela em uma variável local do que acessar a propriedade várias vezes.
