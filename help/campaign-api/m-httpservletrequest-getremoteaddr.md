# getRemoteAddr

Retorna o endereço IP do cliente ou o último proxy que enviou uma solicitação.

```text
getRemoteAddr ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Uma string que contém o endereço IP do cliente que enviou a consulta.

## Recursos

**Método de classe:** [HttpServletRequest](c-httpservletrequest.md)

**Disponível em:**

* JSSP
* WebApp
