# setEnv

>[!WARNING]
>
>Essa função está disponível para um ambiente no local.

>[!NOTE]
>
>Você pode desabilitar esta função passando a opção **XtkSecurity\_Disable\_GetSetEnv** para **true**.

Defina o valor de uma variável de ambiente.

```text
setEnv (name, value)
```

## Parâmetros

**nome** Nome da variável de ambiente.

**Valor** Novo valor para a variável de ambiente.

## Valor de retorno

O novo valor da variável.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia
* Importação
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
