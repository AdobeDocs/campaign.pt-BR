# updateFacebookProfile

```text
Number result = updateFacebookProfile ( String accessToken )
```

## Parâmetros

**accessToken**

## Retornar valor(es)

**result** Retorna a ID da entidade do Adobe Campaign que corresponde ao token de acesso do Facebook. Se o código for diferente de 0, a chamada foi bem-sucedida.
