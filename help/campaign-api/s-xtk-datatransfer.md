# dataTransfer

Scripts de transferência de dados (importação/exportação)

## Métodos

| Método | Descrição |
| --- | --- |
| [Detecção Automática](sm-datatransfer-autodetect.md) | Iniciar uma detecção automática e retornar as primeiras linhas do arquivo |
| [Limpeza](sm-datatransfer-cleanup.md) | Limpar histórico da instância executada |
| [ExportPreview](sm-datatransfer-exportpreview.md) | Calcular a visualização da coluna do arquivo de saída nas primeiras linhas da consulta |
| [GetFilesToDownload](sm-datatransfer-getfilestodownload.md) | Retorna a lista de arquivos usados por esta transferência e encontrados no servidor |
| [RejectExport](sm-datatransfer-rejectexport.md) | Inicia a exportação das rejeições |
| [Start](sm-datatransfer-start.md) | Inicia a transferência de dados |
| [TestCalcField](sm-datatransfer-testcalcfield.md) | Testar o campo calculado usando as linhas de amostra armazenadas no script. |
