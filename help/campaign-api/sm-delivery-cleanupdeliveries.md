# CleanupDeliveries

Especifica que o servidor de mid-sourcing deve excluir determinadas entregas.

```text
CleanupDeliveries ( String deliveryId )
```

## Parâmetros

**deliveryId** Lista de identificadores de entrega no banco de dados de envio (separados por vírgula)

## Retornar valor(es)

Nenhum.
