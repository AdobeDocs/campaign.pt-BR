# GetDbParams

Recupera os parâmetros atuais da fonte de dados.

```text
[ XML dbcnx, XML dbParameters ] = GetDbParams ()
```

## Parâmetros

Nenhum.

## Retornar valor(es)

Definição de fonte de dados **dbcnx**

**dbParameters** Atualize os namespaces e os tablespaces.
