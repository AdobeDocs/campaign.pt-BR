# BuildMirrorEx

Crie a mirror page do HTML.

```text
[ String content, Number responseCode ] = BuildMirrorEx ( String crypted, XML parameters )
```

## Parâmetros

**criptografado** Criptografia reversível para identificadores de partes de mensagens e entregas

**parâmetros** Parâmetros

## Retornar valor(es)

**conteúdo** Conteúdo da mirror page

Resposta HTTP **responseCode** em caso de erro
