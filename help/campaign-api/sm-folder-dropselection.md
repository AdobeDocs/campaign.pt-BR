# SoltarSeleção

Mover seleção para uma pasta da árvore de navegação

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## Parâmetros

Id do esquema de seleção **schema**

**entityFolder** Id da pasta de destino

**selectionList** Seleção para mover

**folderDestId** Pasta de destino

## Retornar valor(es)

Nenhum.

## Recursos

**Esquema:** [xtk:folder](s-xtk-folder.md)

**Estático:**

Sim
