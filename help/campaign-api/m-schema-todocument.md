# toDocument

Converte o esquema em um formulário de documento XML.

```text
toDocument ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Um objeto de tipo [DOMDocument](c-domdocument.md).

* JSSP
* Método SOAP
* WebApp
