# SubmitDeliveryById

Criar e enviar uma entrega a partir de um cenário (identificado por seu nome interno).

```text
Number deliveryId = SubmitDeliveryById ( Number scenarioId, XML content )
```

## Parâmetros

**scenarioId** Identificador de modelo

**conteúdo** conteúdo XML a ser adicionado ao modelo

## Retornar valor(es)

Conteúdo XML de **deliveryId** para adicionar ao modelo
