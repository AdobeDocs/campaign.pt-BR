# sendError

Retorna uma resposta de erro usando o código de erro passado como parâmetro.

```text
sendError (errorCode)
```

## Parâmetros

**errorCode** O código de erro HTTP.

## Valor de retorno

Nenhum.

## Recursos

**Método de classe:** [HttpServletResponse](c-httpservletresponse.md)

**Disponível em:**

* JSSP
* WebApp
