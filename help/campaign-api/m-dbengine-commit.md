# confirmar

Aprova a transação em andamento na conexão.

```text
commit ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Nenhum.

## Observações

Uma transação deve ter sido iniciada previamente usando o método [begin](m-dbengine-begin.md).

* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
