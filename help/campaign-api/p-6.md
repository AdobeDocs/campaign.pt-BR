# Utilização de XML

Muitas APIs do JavaScript usam objetos do tipo XML como parâmetros ou os retornam. As versões anteriores do Adobe Campaign usavam a extensão JavaScript E4X para isso, o que permitia que os elementos XML fossem manipulados diretamente na linguagem. Mas essa tecnologia está lentamente sendo abandonada.

Para substituir essa tecnologia, novos objetos foram adicionados para manipular documentos XML. Eles retomam um subconjunto da interface do Modelo de objeto de documento (DOM) com algumas extensões. Um objeto de notação também está disponível para criar facilmente documentos XML, é uma versão simplificada da convenção JXON BadgetFish.

## Interface DOM

Um objeto [DOMDocument](c-domdocument.md) é um documento XML. Ela pode ser feita a partir de uma cadeia de caracteres, um objeto JXON ou diretamente de um arquivo. Este é um exemplo de criação de um documento DOM:

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

Essa interface é parte da especificação do W3C com várias diferenças notáveis:

* As funções getElements\*, bem como as propriedades childNodes e attributes retornam uma tabela JavaScript em vez de um objeto NodeList. Isso permite o uso das próprias funções das tabelas: forEach, map, ...
* Certas propriedades retornam uma cadeia de caracteres vazia em vez de um valor nulo quando o valor não foi especificado.

Além disso, foram adicionadas determinadas funções de utilitário e algumas extensões não padrão. Por exemplo, para ler ou modificar um atributo, é necessário apenas gravar:

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

em vez de:

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

Atribuir um atributo com a propriedade $name pode pegar uma string, um booleano, uma data ou um número, o valor será convertido automaticamente em uma string de caracteres:

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXON é uma convenção de notação para objetos JavaScript para criar facilmente documentos XML. Essa notação não permite criar todos os documentos XML possíveis. Por exemplo, não permite especificar um elemento com o mesmo nome de um atributo e os namespaces não são gerenciados. Ele é adaptado para documentos do Adobe Campaign. Para necessidades mais complexas, você sempre pode usar as funções DOM tradicionais (analisar ou criar elemento por elemento). O objeto XML é representado por um objeto JavaScript cujas propriedades correspondem aos elementos e atributos. O tipo de valor determina se tem a ver com um elemento ou um atributo.

* String Um atributo cujo valor é a string de caracteres
* Booleano Um atributo cujo valor é &#39;true&#39; ou &#39;false&#39;
* Número Um atributo cujo valor é a representação do número decimal
* Data Um atributo cujo valor é a representação ISO-8601 da data e hora
* Objeto Um elemento
* Matriz Uma lista de elementos

Uma propriedade especial com o nome $ é usada para o conteúdo de texto de um elemento Exemplos:

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML:**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML:**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML:**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

Quando as propriedades contêm caracteres especiais que são identificadores JavaScript inválidos, eles devem ser colocados entre aspas.

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

Objetos JXON podem ser usados em argumentos em qualquer lugar onde uma função antecipa um documento ou elemento XML. Por exemplo:

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

equivale a:

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

É importante observar que a manipulação de documentos XML é feita por objetos DOM. Os objetos JXON são utilitários usados apenas para inicialização. É mais útil criar um documento XML a partir de uma estrutura literal do JavaScript, especialmente quando o documento contém partes variáveis.
