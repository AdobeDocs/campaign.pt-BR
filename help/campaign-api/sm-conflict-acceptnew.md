# AceitarNovo

Aceita a nova versão como a versão atual.

```text
AcceptNew ( String conflictId )
```

## Parâmetros

**conflictId** Identificador de conflito.

## Retornar valor(es)

Nenhum.

## Observações

O conflito é excluído do banco de dados.

## Recursos

**Esquema:** [xtk:conflict](s-xtk-conflict.md)

**Estático:**

Sim
