# SwitchValuesAndAliases

Converte um valor em um alias e vice-versa.

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## Parâmetros

**enums** Coleção das enumerações a serem convertidas.

**mode** Modo de conversão: deve ser &#39;ValuesToAliases&#39; ou &#39;AliasesToValues&#39;.

## Retornar valor(es)

Nenhum.
