# EvaluateJavaScript

Avaliação do código JavaScript.

```text
XML context = EvaluateJavaScript ( String name, String script, XML context )
```

## Parâmetros

**nome** Nome do script.

**script** Código de script a ser executado.

**context** Contexto de execução do teste.

## Retornar valor(es)

**context** Contexto de execução do teste.
