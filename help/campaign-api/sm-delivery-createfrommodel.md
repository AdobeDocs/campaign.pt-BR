# CriarDeModelo

Criação de uma entrega a partir de um modelo (a partir de seu nome interno).

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## Parâmetros

**scenarioName** Nome interno do modelo de entrega

**conteúdo** conteúdo XML a ser adicionado ao modelo

## Retornar valor(es)

**delivery** Retorna o documento de entrega criado
