# createTextNode

Cria um novo nó do tipo texto.

```text
createTextNode (data)
```

## Parâmetros

**dados** Cadeia de caracteres para inserir no nó de texto.

## Valor de retorno

Nó de tipo [DOMCharacterData](c-domcharacterdata.md) criado.
