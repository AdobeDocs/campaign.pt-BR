# SchemaKey (Classe)

Representa a definição de uma chave.

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [rótulo](p-schemakey-label.md) | Retorna a breve descrição da chave. |
| [descrição](p-schemakey-description.md) | Retorna a descrição da chave. |
| [nome](p-schemakey-name.md) | Retorna o identificador da chave. |
| [isInternal](p-schemakey-isinternal.md) | Retorna verdadeiro se a chave for a interna. |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | Retornará true se os campos da chave puderem estar vazios (pelo menos um dos campos deve ser inserido). |
| [campos](p-schemakey-fields.md) | Retorna uma tabela que contém o campo dos campos ( [SchemaNode](c-schemanode.md) ) da chave. |
