# TransformFromId

Transformação de publicação de uma ID de conteúdo

```text
[ String format, String result ] = TransformFromId ( String publishingId, String modelName, String contentId )
```

## Parâmetros

**publishingId** Identificador do modelo de publicação

**modelName** Nome do modelo de transformação

**contentId** Identificador de conteúdo

## Retornar valor(es)

**formato** Formato de saída

**resultado** Resultado da transformação
