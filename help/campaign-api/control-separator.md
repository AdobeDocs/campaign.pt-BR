# Separador

Exibir um separador com um texto e uma imagem.

![Controle separador](assets/separator.70317a27.png)

## Propriedades

**direção - cadeia de caracteres** Horizontal por padrão.

**img - cadeia de caracteres** Imagem associada.

**rótulo - cadeia de caracteres** Texto a ser exibido.

## Observações

Exemplo:

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
