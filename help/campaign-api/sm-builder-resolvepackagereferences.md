# ResolvePackageReferences

Resolve as dependências do pacote

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## Parâmetros

**parâmetros** elemento XML que contém o pacote a ser importado.

## Retornar valor(es)

**patchedPackage** pacote processado.

**warningNb** Número de avisos gerados.
