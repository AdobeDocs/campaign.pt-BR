# AtualizarCustoRealDaLinhaDeDespesa

Atualiza a quantidade real de entregas ou tarefas que usam o item de linha.

```text
UpdateRealCostFromExpenseLine ( Number id, String schema, XML budgetParameters )
```

## Parâmetros

**id** Identificador de entrega/tarefa

**esquema** Esquema de entidade (entrega/tarefa)

**budgetParameters** Item de orçamento na entidade

## Retornar valor(es)

Nenhum.
