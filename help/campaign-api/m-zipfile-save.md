# save

Salva o arquivo.

```text
save ( [filename ] [, overwrite ])
```

## Parâmetros

**filename** Nome do arquivo morto. Se o nome não for especificado ou estiver vazio, o arquivo será salvo com o nome original.

**substituir** Se for &#39;falso&#39;, o arquivo morto não será salvo se já existir um arquivo com esse nome e uma exceção será gerada.

## Valor de retorno

Nenhum.
