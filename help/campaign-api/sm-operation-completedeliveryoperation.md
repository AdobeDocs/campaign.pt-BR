# CompleteDeliveryOperation

Conclui uma entrega criada no contexto de uma campanha.

```text
XML deliveryOut = CompleteDeliveryOperation ( XML deliveryIn, XML parameter )
```

## Parâmetros

**deliveryIn** Entrega de entrada

**parâmetro** Configuração do contexto da campanha

## Retornar valor(es)

**deliveryOut** Entrega atualizada
