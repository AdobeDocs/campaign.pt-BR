# StartValidation

Enviar a oferta para aprovação.

```text
StartValidation ( String offerId, Number type, XML offerSpaces )
```

## Parâmetros

**offerId** ID da oferta.

**type** Tipo de aprovação (targeting=0, content=1)

**offerSpaces** Espaços de oferta a serem aprovados

## Retornar valor(es)

Nenhum.

**Esquema:** [nms:offer](s-nms-offer.md)

**Estático:**

Sim
