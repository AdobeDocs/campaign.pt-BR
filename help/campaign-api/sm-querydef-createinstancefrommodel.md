# CriarInstânciaDoModelo

Instancia uma instância de um objeto por meio de um modelo

```text
Number output = CreateInstanceFromModel ( String schema, Number modelId, XML diff )
```

## Parâmetros

**esquema** Esquema da instância

**modelId** ID do modelo

Correção XML **diff** para aplicar ao modelo

## Retornar valor(es)

**saída** ID da instância criada
