# deleteData

Excluir uma parte do texto.

```text
deleteData (offset, count)
```

## Parâmetros

**deslocamento** Posição do primeiro caractere a ser excluído (0 para o primeiro caractere).

**count** Número de caracteres a serem excluídos.

## Valor de retorno

Nenhum.
