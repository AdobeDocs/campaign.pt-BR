# iOSGenerateCertificate

Codifica o certificado iOS fornecido na base64

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## Parâmetros

**fileName** Nome do arquivo

UUID do aplicativo **uid**

## Retornar valor(es)

**retornar** a versão base64 do certificado
