# BuildOutputNavTree

Mesclar as definições da árvore de navegação encontradas no banco de dados com a definição fornecida no parâmetro.

```text
XML navtree = BuildOutputNavTree ( XML navtreeSource, Boolean save )
```

## Parâmetros

**navtreeSource** árvore de navegação do Source

**salvar** Salve o resultado

## Retornar valor(es)

**navtree** Resultado da mesclagem
