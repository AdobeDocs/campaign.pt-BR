# fromHexString

Carrega o conteúdo de uma string hexadecimal no buffer.

```text
fromHexString (string)
```

## Parâmetros

**cadeia** Uma cadeia de caracteres que representa os dados binários codificados em hexadecimal a serem adicionados ao buffer.

## Valor de retorno

Nenhum.
