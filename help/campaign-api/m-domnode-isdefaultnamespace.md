# isDefaultNamespace

Testa se o namespace fornecido é o padrão.

```text
isDefaultNamespace (namespaceURI)
```

## Parâmetros

**URI do namespace** URI do namespace.

## Valor de retorno

true se namespaceURI for o namespace padrão; caso contrário, false.
