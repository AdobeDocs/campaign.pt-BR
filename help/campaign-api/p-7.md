# Guia de migração do E4X

A extensão E4X para o suporte nativo ao XML no JavaScript é abandonada progressivamente pela Mozilla. A Adobe Campaign usou essa extensão intensamente e, portanto, está se preparando para migrar para uma solução alternativa.

O objetivo deste guia é ajudar você a migrar as configurações existentes ou desenvolver novas configurações descrevendo as soluções substitutas.

O sistema antigo e o novo coexistem, a versão atual do Adobe Campaign é sempre compatível com o E4X, mas novas configurações não devem ser desenvolvidas com a extensão E4X.

Lembrete: o E4X adiciona um tipo de xml do JavaScript que pode ser criado diretamente do programa de origem:

```text
var doc = <xml> ... </xml>
```

ou de uma string:

```text
var doc = new XML ("<xml>...</xml>")
```

Ela pode ser manipulada com uma API específica:

```text
element.@id element.where
```

## Tipo XML

O tipo &quot;xml&quot; nativo foi substituído por uma API DOM, que é do [DOMDocument](c-domdocument.md), [DOMElement](c-domelement.md), [DOMNode](c-domnode.md) tipos, ... o seguinte é o equivalente das operações mais comuns:

> **E4X:**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM:**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X:**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM:**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X:**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM:**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> ou
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

Os documentos XML em um JavaScript devem ser substituídos. Quando este documento deve ser usado para uma função nativa ou uma chamada SOAP transmitindo um documento XML no parâmetro, você pode transmitir um JXON diretamente. Isso será transformado automaticamente em um documento XML (DOMDocument). Caso contrário, você sempre poderá passar por meio de um objeto JXON, mas uma conversão explícita usando a função [DOMDocument.fromJXON](m-domdocument-fromjxon.md) será necessária.

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

Exemplo de equivalência entre a sintaxe XML e JXON:

> **E4X:**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON:**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

Para obter mais informações sobre a sintaxe JXON, consulte a página Uso de XML.

## Chamadas SOAP

Esses métodos do SOAP devem executar as propriedades do objeto NLWS. A JavaScript ID do esquema é criada a partir do namespace e do nome, começando com uma maiúscula. Por exemplo, o esquema nms:delivery terá nmsDelivery como sua ID JS.

> **Antigo:**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **Novo:**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## Métodos do SOAP JavaScript

Para receber um documento XML cujos parâmetros estão no formato DOM em vez do formato E4X, o atributo dom=&quot;true&quot; deve ser adicionado ao esquema.

## Cadeias de caracteres multilinha

O uso de XML para criar cadeias de caracteres de várias linhas deve ser substituído por uma concatenação de cadeias de caracteres, esquecendo-se de adicionar o final da linha \\n.

> **Antigo:**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **Novo:**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```

## Gerenciamento de conteúdo

É necessário ativar a opção DOM no template de publicação ou a partir do template JavaScript durante a pré-visualização. Para uma transformação XSL com pré-processamento JavaScript, você também deve ativar a opção DOM (janela agregadora).
