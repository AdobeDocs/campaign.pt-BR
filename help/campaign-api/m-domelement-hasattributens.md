# hasAttributeNS

Testar a existência de um atributo.

```text
hasAttributeNS (namespaceURI, localName)
```

## Parâmetros

URI **namespaceURI** do namespace de atributo.

**localName** Nome do atributo.

## Valor de retorno

true se o atributo existir; caso contrário, false.
