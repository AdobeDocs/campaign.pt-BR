# packageStatus

Retorna um número que fornece o status do pacote.

```text
packageStatus
```

## Observações

O status do pacote é:

* Schema.PACKAGE\_STATUS\_DEFAULT
* Schema.PACKAGE\_STATUS\_NEVER
* Schema.PACKAGE\_STATUS\_ALWAYS
* Schema.PACKAGE\_STATUS\_PRECREATE
