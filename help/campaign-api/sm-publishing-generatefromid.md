# GenerateFromId

Gera e publica conteúdo referenciado por um identificador em uma pasta

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## Parâmetros

**id** Identificador de conteúdo

**publishingDir** Pasta de publicação

## Retornar valor(es)

**outputFiles** Lista de arquivos gerados
