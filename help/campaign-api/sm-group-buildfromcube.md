# BuildFromCube

Cria a lista com base em uma seleção de células de um cubo.

```text
BuildFromCube ( Number listId, XML conditions )
```

## Parâmetros

Identificador da lista **listId**

**Condições** Condições para definir a criação de lista

## Retornar valor(es)

Nenhum.
