# DuplicateTo

Duplica um novo documento a partir de um documento de origem para uma determinada pasta

```text
session.DuplicateTo ( String pk, String folder )
```

## Parâmetros

**pk** Chave primária do documento de origem

**pasta** Chave primária da pasta de destino

## Retornar valor(es)

Nenhum.
