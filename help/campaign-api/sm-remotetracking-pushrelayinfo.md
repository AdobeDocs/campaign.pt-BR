# PushRelayInfo

Permite fazer o upload de informações sobre uma entrega para os servidores de rastreamento remoto.

```text
PushRelayInfo ( String instance, String dbId, XML document )
```

## Parâmetros

Nome da instância de **instância**

**dbId** Identificador do banco de dados do cliente

**documento** Documento contendo dados

## Retornar valor(es)

Nenhum.

## Recursos

**Esquema:** [nms:remoteTracking](s-nms-remotetracking.md)

**Estático:**

Sim
