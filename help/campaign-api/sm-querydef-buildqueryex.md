# BuildQueryEx

Retorna a consulta gerada e a string de formato

```text
[ String sql, String format ] = queryDef.BuildQueryEx () const
```

## Parâmetros

Nenhum.

## Retornar valor(es)

**sql** Consulta de saída

**format** Cadeia de caracteres de formato, compatível com a função JavaScript sqlSelect().

## Recursos

**Esquema:** [xtk:queryDef](s-xtk-querydef.md)

**Estático:**

Não

**Const:**

Sim

**Somente chave:**

Não
