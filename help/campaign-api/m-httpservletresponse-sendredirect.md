# sendRedirect

Retorna um redirecionamento temporário para outro URL.

```text
sendRedirect (location)
```

## Parâmetros

URL de Redirecionamento de **local**.

## Valor de retorno

Nenhum.

## Recursos

**Método de classe:** [HttpServletResponse](c-httpservletresponse.md)

**Disponível em:**

* JSSP
* WebApp
