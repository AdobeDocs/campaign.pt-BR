# setFile

> Aviso:
>
> O acesso por meio de APIs de arquivo é limitado a **var**, **sftp** e pastas temporárias do Adobe Campaign.

Define o modo de transferência e o arquivo de recebimento.

```text
setFile (filename)
```

## Parâmetros

**filename** Nome do arquivo local.

## Valor de retorno

Nenhum.

## Recursos

**Método da classe:** [FTP](c-ftp.md)

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
