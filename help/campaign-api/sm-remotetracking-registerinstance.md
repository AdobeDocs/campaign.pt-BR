# RegisterInstance

Usado para aprovar uma instância de rastreamento

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## Parâmetros

**instanceName** Nome da instância a ser aprovada

**dbId** Identificador do banco de dados do cliente que está executando uma entrega

**lang** Idioma da instância

## Retornar valor(es)

Nenhum.
