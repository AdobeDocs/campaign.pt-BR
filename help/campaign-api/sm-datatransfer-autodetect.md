# Detecção automática

Iniciar uma detecção automática e retornar as primeiras linhas do arquivo

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## Parâmetros

**fileName** Nome do arquivo

Codificação de caractere de **página de código**

## Retornar valor(es)

**resultado** Retorna as primeiras linhas do arquivo

**Esquema:** [xtk:dataTransfer](s-xtk-datatransfer.md)
