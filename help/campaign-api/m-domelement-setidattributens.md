# setIdAttributeNS

Declara o atributo especificado como um atributo do tipo ID.

```text
setIdAttributeNS (namespaceURI, localName)
```

## Parâmetros

URI **namespaceURI** do namespace de atributo.

**localName** Nome do atributo.

## Valor de retorno

Nenhum.
