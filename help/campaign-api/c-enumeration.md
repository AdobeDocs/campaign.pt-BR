# Enumeração (Classe)

Representa a definição de uma enumeração.

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | Retorna uma cadeia de caracteres que fornece o tipo de enumeração. |
| [padrão](p-enumeration-default.md) | Retorna uma cadeia de caracteres que fornece o valor padrão da enumeração. |
| [descrição](p-enumeration-description.md) | Retorna uma cadeia de caracteres que fornece uma descrição da enumeração. |
| [hasImage](p-enumeration-hasimage.md) | Retorna um booliano que indica se a enumeração tem ou não uma imagem. |
| [rótulo](p-enumeration-label.md) | Retorna uma cadeia de caracteres que fornece o rótulo da enumeração. |
| [nome](p-enumeration-name.md) | Retorna uma cadeia de caracteres que fornece o nome da enumeração. |
| [valores](p-enumeration-values.md) | Retorna um objeto para o qual cada propriedade é um objeto [EnumerationValue](c-enumerationvalue.md) indexado por seu valor. |
