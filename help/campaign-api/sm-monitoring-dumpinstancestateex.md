# DumpInstanceStateEx

Retornar os status dos processos do servidor

```text
XML monitoring = DumpInstanceStateEx ( String mask, Boolean includeDead, Boolean noDatabaseCheck, Number criticalLevel )
```

## Parâmetros

**máscara** Máscara para as instâncias a serem consideradas

**includeDead** Adicionar lista de processos mortos

**noDatabaseCheck** Não verifica alertas de objetos de banco de dados

**criticalLevel** Filtra a severidade dos alertas retornados

## Retornar valor(es)

**monitoramento**
