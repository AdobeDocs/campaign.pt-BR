# integridade

Retorna o tipo de integridade do link.

```text
integrity
```

## Observações

A propriedade pode assumir um dos seguintes valores:

* Schema.INTEGRITY\_NORMAL - link de tipo &quot;Normal&quot;.
* Schema.INTEGRITY\_DEFINE - Link de tipo &quot;Definir&quot;.
* Schema.INTEGRITY\_NEUTRAL - link de tipo &quot;neutro&quot;.
* Schema.INTEGRITY\_USED - link de tipo &quot;usado&quot;.
* Schema.INTEGRITY\_OWN - link de tipo &quot;own&quot;.
* Schema.INTEGRITY\_OWNCOPY - link de tipo &quot;owncopy&quot;.
