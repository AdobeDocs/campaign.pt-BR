# fileIsRelative

Especifica se um nome de arquivo é ou não um nome relativo.

```text
fileIsRelative (fileName)
```

## Parâmetros

**fileName** Nome do arquivo.

## Valor de retorno

O verdadeiro do nome do arquivo é relativo.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
