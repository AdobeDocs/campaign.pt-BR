# PushEvents

Insira uma coleção de eventos.

```text
XML ids = PushEvents ( XML eventCollection )
```

## Parâmetros

**eventCollection** Coleção de eventos.

## Retornar valor(es)

Coleção **ids** contendo a combinação dos identificadores externos e internos usados durante a inserção.
