# sha224

Calcula a assinatura SHA-2 de 224 bits do conteúdo do MemoryBuffer.

```text
sha224 ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Uma string de caracteres que é a representação hexadecimal da assinatura de 224 bits SHA-2.
