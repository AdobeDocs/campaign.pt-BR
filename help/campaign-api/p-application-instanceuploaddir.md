# instanceUploadDir

Caminho completo do diretório &quot;upload&quot; para a instância em que o script é executado.

```text
instanceUploadDir
```

## Observações

O valor retornado considera uma possível sobrecarga do diretório de upload nos parâmetros do servidor.
