# ExcluirDadosRemotos

Excluir dados em instâncias remotas (intermediária e de execução)

```text
DeleteRemoteData ( String address, Boolean midInstance )
```

## Parâmetros

**endereço** Endereço de email ou número de telefone

Solicitação de **midInstance** em instâncias Mid ou Execution

## Retornar valor(es)

Nenhum.
