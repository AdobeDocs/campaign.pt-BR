# descartar

Libera os recursos usados pelo objeto.

```text
dispose ()
```

## Parâmetros

Nenhum.

## Valor de retorno

Nenhum.

## Observações

Esse método é útil para liberar recursos usados pelo objeto sem esperar que ele seja finalizado pelo coletor de lixo ou pelo final do script.
