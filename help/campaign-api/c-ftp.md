# FTP (Classe)

Um objeto FTP permite executar várias operações usando o protocolo FTP.

## Métodos

| Método | Descrição |
| --- | --- |
| [FTP](m-ftp-ftp.md) | Cria um novo objeto para executar comandos FTP. |
| [descartar](m-ftp-dispose.md) | Libera os recursos usados pelo objeto. |
| [lista](m-ftp-list.md) | Retorna a lista de arquivos no servidor em um diretório especificado. |
| [baixar](m-ftp-download.md) | Faz o download de um arquivo do servidor para um arquivo local ou para a memória. |
| [carregar](m-ftp-upload.md) | Baixe um arquivo de um arquivo local para um servidor FTP. |
| [setFile](m-ftp-setfile.md) | Define o modo de transferência e o arquivo de recebimento. |
