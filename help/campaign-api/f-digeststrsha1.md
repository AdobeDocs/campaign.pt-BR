# digestStrSha1

> Aviso:
>
> Esta função não deve ser usada para criar hash com base em Informações pessoais.

Calcula o hash SHA-1 de uma cadeia de caracteres. A cadeia de caracteres é codificada automaticamente em UTF-8 antes do cálculo.

```text
digestStrSha1 (string)
```

## Parâmetros

**cadeia** A cadeia de caracteres na qual o hash deve ser calculado.

## Valor de retorno

O hash SHA-1 da cadeia de caracteres transmitida como um parâmetro.

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia
