# transitionByType

Retorna a transição correspondente ao tipo especificado.

```text
transitionByType (type)
```

## Parâmetros

**tipo** Tipo da transição.

## Valor de retorno

A primeira transição para que o tipo seja passado como um parâmetro, caso contrário, será nulo se a atividade não tiver uma transição desse tipo.
