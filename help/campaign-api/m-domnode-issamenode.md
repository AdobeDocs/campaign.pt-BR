# isSameNode

Testa se a referência fornecida representa o mesmo nó.

```text
isSameNode ()
```

## Parâmetros

Nenhum.

## Valor de retorno

true se ambas as referências representarem o mesmo nó; caso contrário, false.

## Observações

Esse método deve ser usado para comparar duas referências. Os operadores de JavaScript == e === não podem ser usados.
