# LoadChildrenWithPath

Carregar a lista de filhos de um determinado nó

```text
XML result = LoadChildrenWithPath ( String parentKey, String folderFilter, Boolean writeAccess, String fullName, String path, Boolean sort )
```

## Parâmetros

**parentKey** Chave pai

Filtro **folderFilter** em pastas

**writeAccess** A pasta retornada deve ser gravável

**fullName** Nome completo do nó selecionado

**caminho** Nome completo do nó selecionado

**classificar** Classificar por ordem alfabética

## Retornar valor(es)

**resultado** Documento de resultado
