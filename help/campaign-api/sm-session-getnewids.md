# GetNewIds

Coleta uma lista de identificadores de chaves internas para o banco de dados.

```text
String idList = GetNewIds ( Number count )
```

## Parâmetros

**count** Número de identificadores que este método deve retornar

## Retornar valor(es)

**idList** Lista de identificadores separados por vírgulas
