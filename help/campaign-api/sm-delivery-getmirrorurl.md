# GetMirrorURL

Obtém a URL de uma mirror page HTML.

```text
String url = GetMirrorURL ( Number deliveryId, String message )
```

## Parâmetros

**deliveryId** Identificador de entrega

**mensagem** ID da Mensagem

## Retornar valor(es)

URL da página espelhada **url**
