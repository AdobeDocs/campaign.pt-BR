# logWarning

Adiciona uma mensagem de aviso ao log da instância do fluxo de trabalho.

```text
logWarning (message)
```

## Parâmetros

**mensagem** A mensagem a ser adicionada ao log.

## Valor de retorno

Nenhum.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia
* Importação
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
