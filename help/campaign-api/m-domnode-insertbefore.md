# insertBefore

Inserir um nó antes de uma posição específica.

```text
insertBefore (newChild, refChild)
```

## Parâmetros

Nó **newChild** para inserir.

**refChild** Nó filho que deve seguir o nó a ser inserido.

## Valor de retorno

Nó inserido.
