# Salvar

Salva um relatório já gerado no banco de dados.

```text
XML result = Save ( XML data, String reportName )
```

## Parâmetros

**dados** Dados usados pelos relatórios

**reportName** Nome interno do relatório

## Retornar valor(es)

**resultado** Identificador exclusivo e data do registro
