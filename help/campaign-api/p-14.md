# Amostras

## Métodos estáticos

O acesso aos métodos do SOAP é feito chamando um método no objeto que representa o esquema. Os esquemas são objetos globais &#39;NLWS&#39;. O exemplo a seguir invoca o método estático [PostEvent](sm-workflow-postevent.md) do esquema [xtk:workflow](s-xtk-workflow.md).

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## Métodos não estáticos

Para usar os métodos não estáticos do SOAP, você deve primeiro recuperar uma entidade usando os métodos [load](f-load.md) ou [create](f-create.md) nos esquemas correspondentes. O exemplo a seguir invoca o método [ExecuteQuery](sm-querydef-executequery.md) do esquema [xtk:queryDef](s-xtk-querydef.md).

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## Limitações

Determinadas chamadas não estáticas não podem ser usadas porque o objeto que está sendo carregado (\*\*) não tem dados. Este é o caso, por exemplo, para determinadas chamadas em [nms:delivery](s-nms-delivery.md).
