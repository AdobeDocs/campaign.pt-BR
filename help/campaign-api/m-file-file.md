# Arquivo

Cria um novo objeto associado a um arquivo.

```text
File (filename)
```

## Parâmetros

**filename** O nome do arquivo a ser lido ou criado.

## Valor de retorno

Nenhum.

## Observações

Exemplo:

```javascript
var f = new File("/tmp/file.txt")
```
