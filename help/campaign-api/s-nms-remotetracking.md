# remoteTracking

Acesso ao serviço de gerenciamento de rastreamento remoto

## Métodos

| Método | Descrição |
| --- | --- |
| [CriarInstância](sm-remotetracking-createinstance.md) | Usado para criar uma instância de rastreamento |
| [CreateInstanceEx](sm-remotetracking-createinstanceex.md) | Usado para criar uma instância de rastreamento |
| [GetTrackingInfo](sm-remotetracking-gettrackinginfo.md) | Permite que um servidor de redirecionamento remoto baixe informações sobre uma ação de entrega. |
| [GetTrackingLogs](sm-remotetracking-gettrackinglogs.md) | Permite coletar os logs de rastreamento gerados pelo serviço de redirecionamento e rastreamento web. |
| [GetTrackingLogs4](sm-remotetracking-gettrackinglogs4.md) | Permite recuperar os logs de rastreamento gerados pelo servidor de redirecionamento remoto e rastreamento web, usando um formato POST 4.00. |
| [PushRelayInfo](sm-remotetracking-pushrelayinfo.md) | Permite fazer o upload de informações sobre uma entrega para os servidores de rastreamento remoto. |
| [PushTrackingInfo](sm-remotetracking-pushtrackinginfo.md) | Permite fazer o upload de todas as informações relativas a uma entrega para o servidor de rastreamento remoto. |
| [RegisterInstance](sm-remotetracking-registerinstance.md) | Usado para aprovar uma instância de rastreamento |
