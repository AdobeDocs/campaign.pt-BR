# createElementNS

Cria um novo elemento com o nome e o namespace especificados.

```text
createElementNS (namespaceURI, qualifiedName)
```

## Parâmetros

**URI do namespace** URI do namespace.

**qualifiedName** Nome qualificado do elemento a ser criado.

## Valor de retorno

[elemento](c-domelement.md) criado.
