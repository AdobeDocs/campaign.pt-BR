# ZipFile (Classe)

Manipula arquivos Zip.

## Métodos

| Método | Descrição |
| --- | --- |
| [ArquivoZip](m-zipfile-zipfile.md) | Cria um novo objeto Zip associado a um arquivo. |
| [descartar](m-zipfile-dispose.md) | Libera os recursos usados pelo objeto. |
| [abrir](m-zipfile-open.md) | Carrega um arquivo existente. |
| [getEntry](m-zipfile-getentry.md) | Extrai um arquivo do arquivo. |
| [setEntry](m-zipfile-setentry.md) | Adiciona ou atualiza um arquivo no arquivo. |
| [salvar](m-zipfile-save.md) | Salva o arquivo. |

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [contagemArquivo](p-zipfile-filecount.md) | Retorna o número de arquivos no arquivo morto. |
