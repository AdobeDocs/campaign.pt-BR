# PriorizarLogs

Priorizar o log de entrega para uma lista de entregas

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## Parâmetros

**id** Identificador exclusivo de priorização

**entregas** lista de entregas a serem consideradas

Tabela **logTable** contendo todas as mensagens de log

## Retornar valor(es)

Nenhum.

## Recursos

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sim
