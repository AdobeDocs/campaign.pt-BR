# getValue

Retorna o valor do nó referenciado pelo XPath fornecido.

```text
getValue (xpath)
```

## Parâmetros

Caminho **xpath**.

## Valor de retorno

Valor de texto do nó referenciado.

## Observações

A sintaxe do XPath aceita apenas um subconjunto de idioma XPath. Uma exceção será gerada se o caminho estiver mal formado.
