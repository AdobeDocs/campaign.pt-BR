# GenerateForm

Gera o formulário no modo Correspondência ou Web

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## Parâmetros

Nome do formulário **formName**

**mailMode** Gerar um formulário do tipo Email

## Retornar valor(es)

**resultado** Resultado da aplicação do XSL no formulário
