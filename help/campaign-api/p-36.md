# Página Diretiva

Inclui uma biblioteca de funções ou strings.

## Sintaxe

&lt;%@ page import=&quot;lib1, ...&quot; %> &lt;%@ page stringGroup=&quot;groupName&quot; %>

## Descrição

A importação de uma biblioteca de strings expõe um objeto JavaScript global cujo nome começa com sg\_ seguido do nome da biblioteca cujos caracteres especiais foram substituídos por &#39;\_&#39;. Por exemplo, incluir nms:campaign criará a variável sg\_nms\_campaign.

## Exemplo

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
