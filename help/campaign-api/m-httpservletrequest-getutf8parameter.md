# getUTF8Parâmetro

Retorna o valor (codificado em UTF-8) de um parâmetro da consulta.

```text
getUTF8Parameter (name)
```

## Parâmetros

**nome** Nome do parâmetro.

## Valor de retorno

O valor do parâmetro solicitado.

## Recursos

**Método de classe:** [HttpServletRequest](c-httpservletrequest.md)

**Disponível em:**

* JSSP
* WebApp
