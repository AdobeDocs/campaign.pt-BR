# fileSize

Retorna o tamanho de um arquivo em bytes.

```text
fileSize (filename)
```

## Parâmetros

**filename** O nome completo do arquivo.

## Valor de retorno

Retorna o tamanho do arquivo ou -1 se um erro ocorreu (por exemplo, se o arquivo não foi encontrado).

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
