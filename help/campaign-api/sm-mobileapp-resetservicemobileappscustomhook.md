# resetServiceMobileAppsCustomHook

Apaga os parâmetros adicionais de serviços da web em todos os mobileApps no mesmo serviço

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## Parâmetros

**serviceContent** Conteúdo do nó de serviço atual

## Retornar valor(es)

**serviceOut** Conteúdo do nó de serviço após o processamento

## Recursos

**Esquema:** [nms:mobileApp](s-nms-mobileapp.md)

**Estático:**

Sim
