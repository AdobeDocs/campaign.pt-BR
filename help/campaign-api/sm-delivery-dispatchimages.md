# DispatchImages

Instrui o servidor de aplicativos a enviar as imagens para o servidor de mid-sourcing.

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## Parâmetros

**imagens** Lista de imagens a serem carregadas no servidor mid-sourcing.

**providerId** Identificador do roteador de entrega.

**providerName** Nome do roteador de entrega.

## Retornar valor(es)

Nenhum.
