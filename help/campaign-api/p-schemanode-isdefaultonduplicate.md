# isDefaultOnDuplicate

Retorna um valor booleano. Se o valor adicionado for vrai, durante a desduplicação do registro, o valor padrão (definido em defaultValue) será reaplicado automaticamente durante a gravação.

```text
isDefaultOnDuplicate
```
