# BuildSqlSchemaDiff

Gera um documento que descreve as diferenças entre a estrutura real do banco de dados e sua descrição lógica.

```text
XML sqlSchemaDiff = BuildSqlSchemaDiff ( XML sqlDiffParam, XML package )
```

## Parâmetros

Parâmetros de Extensão **sqlDiffParam**

**pacote** Pacote inicial

## Retornar valor(es)

**sqlSchemaDiff** SqlSchemaDiff gerado
