# applyXsl

Transforma um documento XML usando uma folha de estilos XSL.

```text
applyXsl (xslEntity, xml)
```

## Parâmetros

**xslEntity** O nome da folha de estilos XSL armazenada no banco de dados.

**xml** Um documento XML ou uma cadeia de caracteres que contém o documento XML a ser transformado.

## Valor de retorno

O documento XML na forma de uma sequência de caracteres após a transformação.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
