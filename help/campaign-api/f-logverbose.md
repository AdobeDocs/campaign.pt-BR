# logVerbose

Adiciona uma mensagem de informações ao log da instância do fluxo de trabalho. Esta mensagem só é visível no modo &#39;detalhado&#39;.

```text
logVerbose (message)
```

## Parâmetros

**mensagem** A mensagem a ser adicionada ao log.

## Valor de retorno

Nenhum.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia
* Importação
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
