# RegisterGroup2

Adicionar destinatários selecionados a uma lista

```text
RegisterGroup2 ( XML groupList, XML recipientList, XML clearGroup )
```

## Parâmetros

Listas de **groupList**

**recipientList** Lista de destinatários

**clearGroup** Recriar lista

## Retornar valor(es)

Nenhum.

**Esquema:** [nms:recipient](s-nms-recipient.md)

**Estático:**

Sim
