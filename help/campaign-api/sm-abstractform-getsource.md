# GetSource

Código-fonte do gerenciamento de formulários.

```text
[ String source, XML logs ] = GetSource ( String formId, String target, Boolean compiled, String version )
```

## Parâmetros

Identificador de formulário **formId**.

**Target** Tipo de documento a ser gerado.

**compilado** Recupera a versão completa

**versão** Versão do documento para gerar.

## Retornar valor(es)

Código Source de **origem**.

**logs** logs de geração.
