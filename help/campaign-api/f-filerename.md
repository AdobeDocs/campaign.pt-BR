# fileRename

Altera o nome de um arquivo.

Se a codificação de caracteres não for especificada, o padrão do servidor será usado.

```text
fileRename (oldname, newname)
```

## Parâmetros

**oldname** O nome completo do arquivo a ser renomeado.

**newname** O novo nome do arquivo.

## Valor de retorno

Nenhum.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
