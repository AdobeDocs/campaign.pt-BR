# RegisterTransientSchema

Salva um esquema associado aos resultados de uma consulta

```text
RegisterTransientSchema ( String name, String label, String sqltable, XML query )
```

## Parâmetros

**nome** Nome do esquema

**rótulo** Rótulo do esquema

**sqltable** nome SQL da tabela

**consulta** Definição de consulta

## Retornar valor(es)

Nenhum.
