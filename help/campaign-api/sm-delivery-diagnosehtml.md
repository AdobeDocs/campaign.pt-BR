# Diagnosticar HTML

Inicia o diagnóstico de conteúdo HTML

```text
XML diagnostic = DiagnoseHTML ( String htmlContent, Number format )
```

## Parâmetros

**htmlContent** conteúdo do HTML a ser verificado

**formato** O formato do email

## Retornar valor(es)

**diagnostic** Retorna o diagnóstico
