# Entidade (Classe)

Representa uma entidade do banco de dados para um determinado esquema.

Esse objeto não pode ser instanciado diretamente. Você deve usar os métodos create(), get() ou load().

## Métodos

| Método | Descrição |
| --- | --- |
| [salvar](m-entity-save.md) | Salva uma entidade no banco de dados. |

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
