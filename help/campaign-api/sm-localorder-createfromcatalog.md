# CriarDoCatálogo

Criar um pedido a partir de um pacote.

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## Parâmetros

ID do Pacote **catalogId**.

**orgUnitId** ID de entidade local. (opcional)

## Retornar valor(es)

**localOrder** Retorna a ordem criada.

**Esquema:** [nms:localOrder](s-nms-localorder.md)

Sim
