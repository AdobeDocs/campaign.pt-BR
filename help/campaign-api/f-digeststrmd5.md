# digestStrMd5

> Aviso:
>
> Esta função não deve ser usada para criar hash com base em Informações pessoais.

Calcula a função de hash MD5 para uma cadeia de caracteres. A cadeia de caracteres é automaticamente codificada em UTF-8 antes do cálculo.

```text
digestStrMd5 (string)
```

## Parâmetros

**cadeia** A cadeia de caracteres para a qual a função de hash deve ser calculada.

## Valor de retorno

O hash MD5 da cadeia de caracteres transmitida como um parâmetro.
