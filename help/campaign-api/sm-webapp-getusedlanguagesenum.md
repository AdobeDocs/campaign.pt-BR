# GetUsedLanguagesEnum

Cria uma lista discriminada com os idiomas usados no aplicativo web.

```text
XML enum = GetUsedLanguagesEnum ( String designLanguage, String defaultLanguage, XML additionalLanguages )
```

## Parâmetros

**designLanguage** Idioma de design

**defaultLanguage** Idioma padrão

**additionalLanguages** Outros idiomas

## Retornar valor(es)

**enum** Enumeração com os idiomas usados
