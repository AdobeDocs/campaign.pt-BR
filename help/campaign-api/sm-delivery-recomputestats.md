# RecomputeStats

Recalcular estatísticas de entrega e rastreamento para uma ação de entrega.

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## Parâmetros

**deliveryId** Identificador de entrega

**dirtyFlags** campo de bits que descreve o que deve ser recalculado (consulte a enumeração &#39;nms:delivery:dirtyFlags&#39;).

## Retornar valor(es)

Nenhum.

## Recursos

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sim
