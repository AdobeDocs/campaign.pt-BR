# removeAttributeNS

Excluir um atributo.

```text
removeAttributeNS (namespaceURI, localName)
```

## Parâmetros

URI **namespaceURI** do namespace de atributo.

**localName** Nome do atributo.

## Valor de retorno

Nenhum.

## Observações

O método não tem efeito se o elemento não tiver um atributo com esse nome.
