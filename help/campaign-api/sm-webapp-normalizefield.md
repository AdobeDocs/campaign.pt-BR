# NormalizeField

```text
NormalizeField ( XML selectedWebApp, XML archivedField, String newSQLName, String tableName, String schemaId, Boolean rename )
```

## Parâmetros

**seletedWebApp** Lista de pesquisas que podem conter o campo a ser normalizado.

**archivedField** Informações sobre o campo a ser normalizado.

**newSQLName** Novo nome SQL deste campo.

**tableName** Nome da tabela que conterá o novo campo SQL.

**schemaId** Identificador de esquema (exibição) ao qual adicionar uma referência pertencente ao novo campo (opcional).

**renomear** Renomeie também os campos padronizados anteriormente.

## Retornar valor(es)

Nenhum.
