# SaveUrlInfo

Salvar URLs desta entrega como modelos de URL.

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## Parâmetros

**insUrlList** Lista de novas URLs (não associadas a um modelo de URL)

**updUrlList** Lista de modelos de URL a serem atualizados

## Retornar valor(es)

Nenhum.
