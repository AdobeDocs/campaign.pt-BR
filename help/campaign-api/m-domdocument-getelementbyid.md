# getElementById

Retorna o elemento com a ID especificada.

```text
getElementById (elementId)
```

## Parâmetros

**elementId** Identificador do elemento pesquisado. Uma string de caracteres com distinção significativa entre maiúsculas e minúsculas.

## Valor de retorno

O elemento ou nulo se o documento não contiver nenhum elemento com uma ID específica.
