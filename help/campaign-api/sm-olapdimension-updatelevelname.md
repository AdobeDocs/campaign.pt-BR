# UpdateLevelName

Atualiza o nome interno de um nível com base em sua expressão.

```text
XML result = UpdateLevelName ( XML level, XML dimension )
```

## Parâmetros

**nível** Nível a ser modificado

**dimensão** Dimensão pai do nível

## Retornar valor(es)

**resultado** Nível modificado

## Recursos

**Esquema:** [xtk:olapDimension](s-xtk-olapdimension.md)

**Estático:**

Sim
