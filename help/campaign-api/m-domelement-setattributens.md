# setAttributeNS

Altere o valor de um atributo ou crie um novo atributo.

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## Parâmetros

URI **namespaceURI** do namespace de atributo.

**qualifiedName** Nome qualificado do atributo.

**value** Valor de texto do atributo.

## Valor de retorno

Nenhum.
