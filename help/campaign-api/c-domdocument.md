# DOMDocument (Classe)

Documento XML.

## Métodos

| Método | Descrição |
| --- | --- |
| [DOMDocument](m-domdocument-domdocument.md) | Cria um novo documento. |
| [fromXMLString](m-domdocument-fromxmlstring.md) | Cria um novo documento a partir de uma cadeia de caracteres XML. |
| [doJXON](m-domdocument-fromjxon.md) | Cria um novo documento de um objeto JXON. |
| [carregar](m-domdocument-load.md) | Cria um novo documento de um arquivo XML. |
| [toXMLString](m-domdocument-toxmlstring.md) | Converte o documento XML em uma cadeia de caracteres. |
| [createElement](m-domdocument-createelement.md) | Cria um novo elemento. |
| [createElementNS](m-domdocument-createelementns.md) | Cria um novo elemento com o nome e o namespace especificados. |
| [createTextNode](m-domdocument-createtextnode.md) | Cria um novo nó do tipo texto. |
| [criarComentário](m-domdocument-createcomment.md) | Cria um novo nó do tipo comentário. |
| [createCDATASection](m-domdocument-createcdatasection.md) | Cria um novo nó do tipo CDATA. |
| [createProcessingInstruction](m-domdocument-createprocessinginstruction.md) | Cria uma nova instrução de processamento. |
| [createEntityReference](m-domdocument-createentityreference.md) | Cria uma nova referência de entidade. |
| [getElementsByTagName](m-domdocument-getelementsbytagname.md) | Retorna a lista de todos os elementos com o nome especificado. |
| [getElementsByTagNameNS](m-domdocument-getelementsbytagnamens.md) | Retorna a lista de todos os elementos do documento com o nome e o namespace especificados. |
| [getElementById](m-domdocument-getelementbyid.md) | Retorna o elemento com a ID especificada. |
| [importNode](m-domdocument-importnode.md) | Cria uma cópia de nó de outro documento. |
| [normalizeDocument](m-domdocument-normalizedocument.md) | Normaliza o documento: as referências da entidade são substituídas e os nós de texto adjacentes são fundidos. |
| [renameNode](m-domdocument-renamenode.md) | Altera o nome de um elemento ou atributo. |

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [raiz](p-domdocument-root.md) | O elemento raiz do documento. Esta propriedade é sinônima a [documentElement](p-domdocument-documentelement.md). |
| [documentElement](p-domdocument-documentelement.md) | Elemento raiz do documento. |
| [URIdoDocumento](p-domdocument-documenturi.md) | URI do namespace do documento. |
