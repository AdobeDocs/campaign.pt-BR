# GetInputValues

Pesquisa os valores possíveis para uma zona de entrada de um formulário.

```text
XML options = GetInputValues ( String schema, XML input )
```

## Parâmetros

**esquema** Esquema de edição de pesquisa.

**entrada** Zona de entrada.

## Retornar valor(es)

**opções** Valores possíveis para esta zona de entrada.
