# cusResource

Mapeamento de dados para replicação

## Métodos

| Método | Descrição |
| --- | --- |
| [CreateCusResource](sm-cusresource-createcusresource.md) | Criar automaticamente recursos personalizados com a descoberta automática de campos/índice/link/chave. |
| [CriarEsquemaFDAS](sm-cusresource-createfdaschema.md) | Crie automaticamente esquemas usados pelo FDA a partir de recursos personalizados do ACS. |
| [GenerateCusResources](sm-cusresource-generatecusresources.md) | Envia todos os recursos personalizados do conjunto de recursos personalizados do ACS. |

## Métodos genéricos

| Método | Descrição |
| --- | --- |
| [criar](f-create.md) | Cria uma nova entidade correspondente a um determinado esquema. |
| [carregar](f-load.md) | Carrega e retorna uma entidade correspondente a um determinado esquema e chave. |
| [salvar](m-entity-save.md) | Salva uma entidade no banco de dados. |
