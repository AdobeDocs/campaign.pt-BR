# getOption

Retorna o valor de uma opção na tabela de opções.

```text
getOption (name [, useCache ])
```

## Parâmetros

**nome** Nome da opção.

**useCache** Use o cache de valores de opção (por padrão, ele não é usado).

## Valor de retorno

O valor da opção se a opção existir, caso contrário, indefinido. O tipo do valor depende do tipo da opção.

## Recursos

**Disponível em:**

* Gerenciamento de conteúdo
* Propriedades de entrega
* Regra de tipologia
* JSSP
* Método SOAP
* WebApp
* Fluxo de trabalho
