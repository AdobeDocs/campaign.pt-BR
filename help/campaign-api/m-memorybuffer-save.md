# save

> Aviso:
>
> O acesso por meio de APIs de arquivo é limitado a **var**, **sftp** e pastas temporárias do Adobe Campaign.

Salva o conteúdo do buffer em um arquivo.

```text
save (filename)
```

## Parâmetros

**filename** O nome do arquivo a ser salvo.

## Valor de retorno

Nenhum.

## Recursos

**Método de classe:** [MemoryBuffer](c-memorybuffer.md)

* Gerenciamento de conteúdo
* Propriedades de entrega
* Mensagem de entrega
* Regra de tipologia

* Método SOAP
* WebApp
* Fluxo de trabalho
