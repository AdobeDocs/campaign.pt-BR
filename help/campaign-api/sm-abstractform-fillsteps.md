# FillSteps

Criar pontos de corte automaticamente para um número igual de compartimentos.

```text
XML samplingSteps = FillSteps ( String schema, String expr, Number classCount )
```

## Parâmetros

**esquema** Esquema raiz da análise

**expr** expressão Source

**classCount** Número de compartimentos a serem gerados

## Retornar valor(es)

**samplingSteps** Lista de etapas

## Recursos

**Esquema:** [xtk:abstractForm](s-xtk-abstractform.md)

**Estático:**

Sim
