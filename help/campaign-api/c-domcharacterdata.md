# DOMCharacterData (Classe)

Um nó que contém somente texto. Pode ser um nó do tipo texto ou um comentário.

## Métodos

| Método | Descrição |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | Extrair uma parte do texto. |
| [appendData](m-domcharacterdata-appenddata.md) | Adicione uma cadeia de caracteres ao texto. |
| [insertData](m-domcharacterdata-insertdata.md) | Insere uma cadeia de caracteres no texto em uma posição específica. |
| [deleteData](m-domcharacterdata-deletedata.md) | Excluir uma parte do texto. |
| [replaceData](m-domcharacterdata-replacedata.md) | Substituir uma parte do texto. |

## Propriedades

| Propriedade | Descrição |
| --- | --- |
| [dados](p-domcharacterdata-data.md) | Valor de texto do nó. |
| [comprimento](p-domcharacterdata-length.md) | Número de caracteres no nó. |
