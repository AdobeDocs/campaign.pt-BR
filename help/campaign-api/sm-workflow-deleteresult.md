# DeleteResult

Apaga os resultados de uma ou mais atividades.

```text
DeleteResult ( String workflowId, String activityName )
```

## Parâmetros

**workflowId** Identificador ou nome interno do fluxo de trabalho.

**activityName** Nome da(s) atividade(s) cujos resultados você deseja apagar

## Retornar valor(es)

Nenhum.
