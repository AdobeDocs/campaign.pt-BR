# reverseLink

Se o elemento for um link, retornará um objeto [SchemaNode](c-schemanode.md) que representa um link reverso (por meio do esquema de destino). Caso contrário, a propriedade não será definida.

```text
reverseLink
```

## Recursos

**Propriedade da classe:** [SchemaNode](c-schemanode.md)

**Somente leitura:**

Sim
