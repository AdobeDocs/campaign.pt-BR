# conflito

> Aviso: essa função está disponível para um ambiente no local.

Armazenamento temporário das entidades em conflito.

## Métodos

| Método | Descrição |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | Mantém a versão atual. |
| [AceitarNovo](sm-conflict-acceptnew.md) | Aceita a nova versão como a versão atual. |
| [ConjuntoResolvido](sm-conflict-setresolved.md) | Declara uma entidade como não tendo mais conflitos. |

## Métodos genéricos

| Método | Descrição |
| --- | --- |
| [criar](f-create.md) | Cria uma nova entidade correspondente a um determinado esquema. |
| [carregar](f-load.md) | Carrega e retorna uma entidade correspondente a um determinado esquema e chave. |
| [salvar](m-entity-save.md) | Salva uma entidade no banco de dados. |
