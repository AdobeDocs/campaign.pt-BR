# CheckAccess

Verifica se o operador atual pode acessar a tarefa.

```text
Boolean result = CheckAccess ( XML taskEntity )
```

## Parâmetros

**taskEntity** Entidade da tarefa

## Retornar valor(es)

**resultado** Valor de retorno do método (sim/não)
