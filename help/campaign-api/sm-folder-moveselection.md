```text
MoveSelection ( String schemaId, String entityFolder, XML selectionList, String key )
```

## Parâmetros

**IDdoEsquema** ID do esquema de seleção

**entityFolder** Id da pasta de destino

**selectionList** Seleção para mover

Chave do nó **key**

Nenhum.
