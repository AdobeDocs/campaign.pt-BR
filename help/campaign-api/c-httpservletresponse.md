# HttpServletResponse (Classe)

Representa a resposta de um servlet retornada a um cliente.

Há apenas uma instância desta classe acessível pela variável `response`.

## Métodos

| Método | Descrição |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | Altera o tipo de documento da resposta. |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | Retorna um redirecionamento temporário para outro URL. |
| [addCookie](m-httpservletresponse-addcookie.md) | Adiciona um cookie à resposta. |
| [addHeader](m-httpservletresponse-addheader.md) | Adiciona um cabeçalho HTTP adicional à resposta. |
| [sendError](m-httpservletresponse-senderror.md) | Retorna uma resposta de erro usando o código de erro passado como parâmetro. |
